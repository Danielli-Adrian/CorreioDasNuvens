# Correio das Nuvens

O último avião postal do dia leva uma carta ao farol. Desvie das nuvens de tempestade no caminho. Cada nuvem evitada vale um ponto.

## Tecnologias

Python, Pygame, pyttsx3 e cx_Freeze. A pontuação é registrada em JSON por linha no arquivo `log.dat`.

## Como jogar

Instale as dependências com `python -m pip install pygame-ce pyttsx3 cx-Freeze` e, na pasta do projeto, inicie com `python main.py`. Digite seu nome na janela do terminal. Use as setas para cima e para baixo para pilotar, Espaço para pausar ou continuar e Esc para sair.
